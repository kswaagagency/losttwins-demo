# Lost Twins — Image Assets

Place the approved Lost Twins images in this folder.

## Recommended files
- `logo.png` — brand logo (transparent PNG or SVG)
- `hero.jpg` — main homepage/banner image
- `lookbook-01.jpg`, `lookbook-02.jpg`, `lookbook-03.jpg` — gallery/lookbook images
- `about.jpg` — brand or team image
- `product-01.jpg`, `product-02.jpg`, `product-03.jpg` — product images (if applicable)

## Asset rules
- Use original images supplied by Lost Twins or images you have permission to use.
- Prefer clear, high-resolution images; keep filenames lowercase and use hyphens.
- Do not add private, personal, or unapproved customer photos.

No image files were available in the repository when this folder was created, so this is the organised asset location and upload guide—not a claim that photos have been added.
